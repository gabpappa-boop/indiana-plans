# indiana-plans
To get to the graph that was produced for this github I had to go through a few steps. First I went to the healthcare.gov website where I scrolled to the bottom of the page to research the section that had information for research. I then got the information of health plans that regarded families and individuals. After this I downloaded the most recent years data set (2026) and then put it into excel to review the data. The reason I put it into excel first was because I wanted to better understand the data that was being produced. After reviewing I put the data set into claude and copied the prompt that was used in the slide deck we reviewed for pre-class 12. Claude then produced the plot that can be viewed. I then asked Claude to simplify the meaning of the graph when regarding premiums and deductibles. It produced this which I thought was sufficient based on my understanding. “Each dot is an Indiana plan in a county, with premium on the x-axis and deductible on the y-axis. The dots slope downward: plans with higher premiums tend to have lower deductibles. In this data the correlation is about −0.77, which is a fairly strong negative relationship.”
